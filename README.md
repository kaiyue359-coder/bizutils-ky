# bizutils-ky

A small collection of practical business utilities.

## Tools

- [SQL Server Viewer](tools/sql-server-viewer/) - a lightweight read-only SQL Server data viewer.
- [Plan Annotation Tool](tools/annotation/) - a browser-only tool for marking regions on PDFs and images.
- [Personal Invoice Pool](tools/personal-invoice-pool/) - a local-only invoice usage tracker.
